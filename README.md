# 🌌 FoodVerse: Explore Foods as Planets in a 3D Universe

> **“What if nutrition could be explored like a galaxy?”**
> Welcome to **FoodVerse** — a 3D immersive platform that transforms the way people learn about food and nutrition.
> Each planet represents a **food item**, each orbit a **nutrient category**, and each journey a **learning experience powered by AI**.

---

## 🚀 The Vision

In today’s fast-paced world, people struggle to understand what they eat. Nutritional charts are boring, health apps are cluttered, and learning about food feels like homework.
So we asked: *What if exploring nutrition was as exciting as exploring the cosmos?*

That’s how **FoodVerse** was born — an interactive 3D universe where food comes alive, powered by **AI and creativity**.

---

## ✨ Core Features

### 🪐 1. 3D Food Universe

* Every **food item** is visualized as a **planet** in a dynamic 3D space.
* Zoom in, rotate, and explore foods orbiting their respective nutrient stars (like Protein, Carbs, Vitamins, etc.).

### 🤖 2. AI-Powered Nutrition Insights

* Powered by **OpenAI / Gemini API**, users can chat with an **AI Nutrition Guide**.
* Get instant breakdowns: calories, macros, health benefits, or even recipe ideas — all explained conversationally.

### 🍱 3. Smart Food Recommendation Engine

* The AI suggests healthier alternatives, meal combos, or balanced diet plans based on your goals.
* Whether you’re bulking, cutting, or just curious — FoodVerse adapts to *you*.

### 🌈 4. Educational & Fun Interface

* A beginner-friendly visual environment that simplifies complex data.
* Ideal for students, educators, and anyone exploring nutrition interactively.

### 🎮 5. Gamified Experience (Future Scope)

* Earn “Star Dust Points” for discovering new foods.
* Unlock achievements and build your own **Healthy Galaxy**.

## 🧠 AI Model / API Used

| Component                               | Description                                                               |
| --------------------------------------- | ------------------------------------------------------------------------- |
| **OpenAI GPT / Google Gemini API**      | For generating nutritional insights, Q&A, and smart food recommendations. |
| **Three.js / React-Three-Fiber**        | For rendering the 3D universe of foods and planets.                       |
| **Firebase / Flask Backend (Optional)** | For user data management, authentication, and progress saving.            |

---

## 🛠️ Tech Stack

* **Framework:** Next.js 15 (App Router)
* **Language:** TypeScript, React 19
* **3D Graphics:** Three.js, @react-three/fiber, @react-three/drei
* **Styling:** TailwindCSS v4, shadcn/ui components
* **Animations:** Framer Motion

> Note: the AI chat, recommendation engine and backend listed in the vision sections above are planned / pitch features — they are not part of this repository's code, which is the Next.js 3D explorer described by the stack above.

## 🧩 Installation & Setup

```bash
# Clone this repository
git clone https://github.com/MSAbhishek22/foodverse-3d-health-explorer-1.git

# Navigate into the project directory
cd foodverse-3d-health-explorer-1

# Install dependencies
npm install

# Run the development server
npm run dev
```

Then open `http://localhost:3000` in your browser.
